# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Release

### Added
- Complete single-page application (SPA) architecture using React and Vite.
- Glassmorphic UI design system with custom Tailwind CSS configurations.
- Full bilingual support (English and Bahasa Malaysia) using custom Context provider.
- Smooth scrolling integration using Lenis.
- Interactive custom cursor and scroll progress indicators.
- "Easter Egg" Matrix rain animation triggered by typing "STEM" or 5-tap on the logo.
- Team directory, FAQ accordion, Projects showcase, and Web Hosting request sections.
- OpenGraph and Twitter card SEO tags.
- Dedicated `robots.txt` and `sitemap.xml` for search engine visibility.
- Mobile responsive layout scaling.
- Comprehensive project documentation (README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, INSTALLATION).
