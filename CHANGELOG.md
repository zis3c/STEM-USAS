# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Release

### Added

- Complete single-page application (SPA) architecture using React 19 and Vite 8.
- Glassmorphic UI design system built with Tailwind CSS 4.
- Full bilingual support (English and Bahasa Malaysia) using a custom Context provider.
- Light and dark themes with a pre-paint theme script to prevent flashing.
- Smooth scrolling integration using Lenis.
- Scroll progress and reveal animations.
- "Easter Egg" Matrix rain animation triggered by typing "STEM" or 5-tap on the logo.
- FAQ accordion and Projects showcase sections.
- Membership registration and a member stats widget with a graceful fallback.
- Browser console banner with version and commit information.
- OpenGraph and Twitter card SEO tags.
- Dedicated `robots.txt` and `sitemap.xml` for search engine visibility.
- Cloudflare Pages deployment with security headers and a Content Security Policy.
- Mobile responsive layout scaling.
- Continuous integration with lint, security lint, TypeScript checks, unit tests, CodeQL, and dependency review.
- Comprehensive project documentation (README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, INSTALLATION).
