# Security Policy

## Supported Versions

Currently, only the latest `main` branch of the STEM USAS landing page is officially supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover any security-related issues (e.g., exposed API keys, cross-site scripting vulnerabilities, denial of service flaws), please do not report them via public GitHub issues.

Instead, please report the vulnerability directly to the Tech Lead via Telegram at [t.me/STEMUSAS](https://t.me/STEMUSAS) or direct message to the current repository owner (`@zis3c`).

We will:
1. Acknowledge the receipt of your vulnerability report.
2. Provide an estimated timeline for addressing the vulnerability.
3. Notify you when the vulnerability has been patched.

Thank you for helping keep the STEM USAS community and our projects secure!
